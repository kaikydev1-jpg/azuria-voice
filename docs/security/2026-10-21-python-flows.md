# Fluxos Python — alertas #18–44

Revisão do código em `202a7397` e correções na branch de auditoria.
Os números são de Code Scanning, não de Dependabot. Protegido significa que há
controle no fluxo examinado; não é garantia contra um atacante local que já
possa substituir arquivos do usuário nem encerramento do alerta no GitHub.
