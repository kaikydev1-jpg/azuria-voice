# JavaScript e Bandit — triagem individual

Os números são de Code Scanning. “Not confirmed” indica que a análise não
demonstrou entrada controlada por atacante chegando ao efeito alegado.
Isso não encerra alertas automaticamente. A falha de PIN e o cancelamento do
listener foram corrigidos; a função de compartilhamento LAN foi preservada.

| #513 | `js/xss-through-dom`, `electron/src/renderer/src/features/longform/book-settings.tsx:93` | Not confirmed / analyzer sink mismatch. The reported sink assigns the **constant empty string** to the file input's `value`, clearing the picker. Metadata and pronunciation values go into React input `value` props and React text nodes, never HTML parsing APIs. | #515 | `js/shell-command-injection-from-environment`, `electron/src/main/backend.ts:997` | Not confirmed. Sink is Node `spawn(command, args, options)` with **no shell**. Selecting the owner's tool executable is an intentional trust boundary, not untrusted shell interpolation. |
